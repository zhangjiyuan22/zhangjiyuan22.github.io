Selected Research Contributions

AdaMGrid
Adaptive grids and large-scale parameter search

Developed reusable adaptive magnification maps and interpolation, achieving more than 1,000× acceleration and enabling a cluster-scale triple-lens global search.

FastVBLensing
Algorithmic and C++ optimization

Reduced a core contour-integration operation from O(N²) to O(N log N) using an augmented priority queue and a skip list, obtaining more than 3× overall acceleration.

MetalLens
Physics-informed inference for distant M dwarfs

Combined multi-band photometry, microlensing geometry, and stellar models to break mass-distance-extinction-metallicity degeneracies.

Undergraduate thesis
IGBT dynamic junction-temperature computation

Built an end-to-end framework connecting measured electrical waveforms, experimentally calibrated loss models, and a thermal-impedance network.
