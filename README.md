# Jiyuan Zhang — Personal Website

Static source for [zhangjiyuan22.github.io](https://zhangjiyuan22.github.io/).

## Deploy on GitHub Pages

1. Create a public GitHub repository named exactly `zhangjiyuan22.github.io`.
2. Upload the contents of this folder to the repository root. Do not upload the enclosing folder itself.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and the `/ (root)` folder, then save.
6. After GitHub finishes deployment, open `https://zhangjiyuan22.github.io/`.

The site is dependency-free: it uses plain HTML, CSS, and JavaScript, with no external fonts or frontend libraries.

## Structure

- `index.html` — home and about
- `projects.html` — selected technical projects
- `publications.html` — publication list
- `talks.html` — conference and invited talks
- `cv.html` — embedded résumé and download link
- `assets/` — styles, script, portrait, favicon, and résumé PDF

## Updating

Edit the HTML files directly and push the changes to `main`. GitHub Pages will redeploy automatically.
