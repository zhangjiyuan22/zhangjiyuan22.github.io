Adaptive computation · HPC

AdaMGrid

GitHub ↗

Conventional grid searches repeatedly evaluate the same expensive magnification pattern along many trial trajectories. AdaMGrid reformulates the workflow: it precomputes an adaptive magnification map once, then reuses it through interpolation throughout the search.

  • Recursively refines the source plane according to local interpolation error, concentrating resolution near high-gradient regions.
  • Reduces repeated numerical evaluations while explicitly controlling interpolation accuracy.
  • Achieves more than three orders of magnitude speedup over direct calculation.
  • Deployed through a large-scale parallel search totaling approximately five million CPU-hours, making systematic exploration of the triple-lens parameter space feasible.

Algorithms · Data structures · C++

FastVBLensing

GitHub ↗Talk ↗

FastVBLensing targets a quadratic-complexity bottleneck inside contour-integration software used for gravitational microlensing calculations.

  • Designed an augmented priority queue and applied a skip list to reduce the core operation from O(N²) to O(N log N).
  • Implemented the optimization in the underlying C++ codebase.
  • Validated performance and numerical accuracy across the complete operating range.
  • Obtained more than 3× overall acceleration while preserving the original precision.

Inverse problems · Identifiability

MetalLens

GitHub ↗arXiv ↗

The metallicities of distant M-dwarf microlensing lenses are difficult to measure directly. MetalLens introduces a joint inference method combining multi-band photometry, microlensing geometric constraints, and stellar physical models.

  • Uses complementary physical responses to break degeneracies among stellar mass, distance, extinction, and metallicity.
  • Propagates observational and model uncertainties through an end-to-end inference framework.
  • Opens a route to systematic metallicity measurements for M dwarfs out to the Galactic bulge.
  • Designed for the lens sample expected from the Nancy Grace Roman Space Telescope.

Power electronics · Experiment

IGBT Junction-Temperature Computation

Undergraduate thesis project establishing an end-to-end computation framework from measured current and voltage waveforms to the dynamic junction temperature of an IGBT power device.

  • Experimentally characterized conduction and switching losses across device operating conditions.
  • Coupled the calibrated loss model to a thermal-impedance network for dynamic temperature computation.
  • Applied the framework to a representative inverter operating condition.
  • Obtained close agreement with Infineon's official IPOSIM power-device simulation tool.
